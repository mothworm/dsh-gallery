## 二、第三方成分说明（Third-party components）

这一节如实交代"哪些东西不是我们原创的"，好让再分发的人知道边界在哪。

**A. 代码：无第三方源码。**

两个插件的 `package.json` 里 `dependencies` 与 `peerDependencies` 均为空，
运行期的 `@deepseek-ai/*` 由宿主自己提供（插件从磁盘不解析它们）。
仓库中没有任何从他人仓库复制/改写的源文件，因此**无需随附第三方著作权声明**。

复查（在仓库根目录执行，两条都应无输出或只命中文档本身）：

```bash
git grep -n -I -E 'copy from|based on|ported from|adapted from' -- .
git grep -n -I -E 'github\.com|npmjs\.com' -- .
```

**B. 随插件分发的风景图：本项目自产。**

`dsh-boot-suites/gallery/arts-builtin/` 里的三套共 12 张风景图由本项目用本地部署的
ComfyUI 生成（生成脚本见 `dsh-gallery-pack/tools/pack-scenery.py`），
**不含任何他人角色或美术作品**，不受第三方许可约束。
若你据此再分发，按 `LICENSE` 里 BSD-3-Clause 的条款处理即可。

**C. 其它主题素材：不在本仓库。**

本仓库不附带、也不分发任何第三方主题素材。若你从别处拿到素材包并导入本机，
那些素材**版权归各自权利人**，请自行确认使用权；本项目的代码授权不覆盖它们。

**D. 曾收录但已移除的第三方素材。**

开发过程中曾用过一套以他人二创角色为原型的主题，其插画采用
CC BY-NC-SA 4.0（署名 / 非商用 / 相同方式共享），与本仓库 BSD-3-Clause

本仓库与插件包中均不含其任何字节。上面 A/B 两节的结论因此成立。

它只出现在脚本注释里，用来说明图片是"怎么生成的"。
ComfyUI 本身是第三方软件，**不随本仓库分发**，也不构成对其的任何背书关系。

## 三、为什么这份说明不放在 LICENSE 里

2026-11-24 之前，上面这些内容附在 `LICENSE` 文件末尾。但 GitHub 的许可证识别器
会把整个文件与标准模板逐字比对，**只要多出内容就判定为 `Other`**，
仓库页面上因此显示不出 `BSD-3-Clause` 徽章。

拆成两个文件后：

- [`LICENSE`](../LICENSE) = 逐字的标准 BSD-3-Clause → GitHub 能正确识别
- 本文 = 边界说明 → 内容一点没少，而且在这里可以正常排版、加链接

法律效力不受影响：`LICENSE` 里的条款就是完整的授权，本文只做说明。
