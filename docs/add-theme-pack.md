# 添加主题素材包

> 一份主题 = 一个目录。放进去、刷新面板就有，**不用改任何代码**。
> 本文只讲"怎么加"，字段的权威定义以 `dsh-boot-suites/gallery/arts-builtin/` 里那三套现存主题为准——它们是能跑通的样板。

> **本文讲什么**：**一套主题长什么样** —— 目录结构、`preset.json`、图片序列与视频的区别、加完之后怎么验证。
>
> **手上已经有素材包、只想装进去**？看
> **[dsh-gallery-pack/tools/添加主题素材包.md](../dsh-gallery-pack/tools/添加主题素材包.md)**
> —— 那篇讲导入脚本 `import-theme.py` / `build-index.py --verify` 的实际用法。

## 1. 目录放哪儿

| 平台 | 路径 |
|---|---|
| macOS / Linux | `~/.dsh/boot-naruto/arts/` |
| Windows | `%USERPROFILE%\.dsh\boot-naruto\arts\`（PowerShell：`$HOME\.dsh\boot-naruto\arts\`） |

这是**宿主真正读素材的地方**。注意它不在 `node_modules` 里——安装脚本把自带三套拷过来就是为了这件事。

```
~/.dsh/boot-naruto/arts/
├── scenery-cool/        # 自带 · 清寒
├── scenery-warm/        # 自带 · 暖秋
├── scenery-dark/        # 自带 · 夜潮
└── 你的主题目录/         # 自己加的
    ├── preset.json
    ├── （开屏分镜用图）
    ├── （桌面壁纸用图）
    └── （悬浮球图案）
```

---

## 2. 一套主题里有什么

| 文件/目录 | 作用 | 能不能省 |
|---|---|---|
| `preset.json` | 主题配置：名字、分镜顺序、动画参数、配色 | 不能省（面板靠它列出来） |
| 图片（png / jpg / webp） | 开屏分镜的画面 + 桌面壁纸 | 至少要有一张能当壁纸 |
| 悬浮球图案 | 桌面上那颗小球里显示的图标 | 可省（省了用默认图案） |
| 调色文件 | 卡片配色 | **可省**——没有就走 `normalizePalette(null)` 的默认配色，并在 `boot.log` 记一条 `palette-missing`（正常，不是错误） |

**最快上手的方式**：把 `arts-builtin/scenery-cool/` 整个复制成 `我的主题/`，改名、换图、改 `preset.json` 里的显示名。先跑通再谈自定义。

## 3. 开屏画面：图片序列 vs 视频

两种都支持，行为不一样：

| 类型 | 什么时候用 | 时长特征 |
|---|---|---|
| **图片序列**（若干张图 + 推镜/视差） | 素材是静图时 | 预设 **4 幕 ≈ 6 秒** |
| **视频**（mp4） | 想放"招募动画"那种整段动起来的效果 | 常见 **≈ 13 秒** |

- 走视频这条路的，`preset.json` 里要把它标成视频模式（参照自带/示例里 `mode=video` 的写法），mp4 的分段规则见 `dsh-boot-gallery/README.md`。
- **只放几张静图却在 `preset.json` 里声称视频**，会退化成图片分镜播——这就是"点了重播没反应 / 播出来的不是那个动画"最常见的原因。

## 4. 加完之后怎么验证（4 步，都能自己看）

1. **面板里数量变了**：点悬浮球 → 面板标题从「共 3 套」变成「共 4 套」（自带三套 + 你这一套）。
   没变 → 目录放错地方，或 `preset.json` 名字/结构不合法。
2. **点一下能换**：选中你的主题 → 桌面壁纸和开屏画面**同时**变（本来就是同一批图）。
3. **开屏能播**：点「立刻重播开机」。没反应 → 看第 3 节，多半是素材类型和 `preset.json` 对不上。
4. **看日志**：`~/.dsh/boot.log` 里应有这次切换的记录——
   ```
   BOOT preset <主题名>        # 图片序列开屏
   BOOT video <主题名>         # 视频开屏
   palette-missing            # 没有调色文件，用默认配色（正常）
   ```

## 5. 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板里 0 套 / 开屏黑屏 + 红圈 | `arts/` 是空的（常见于只装了页面侧、没跑 `install-arts.mjs`） | `node dsh-boot-suites/gallery/tools/install-arts.mjs` |
| 面板里没有你的主题 | 目录放进了 `node_modules`、或 `preset.json` 不在目录根上 | 放到 `~/.dsh/boot-naruto/arts/<主题>/preset.json` |
| 壁纸换了但开屏没变（或反之） | 主题里只配了一边 | 一套主题同时管两处，检查 `preset.json` 里的画面引用 |
| 点重播没反应 | 声称视频但素材是静图 / 素材缺失 | 统一成一种；或补 mp4 |
| 日志里有 `palette-missing` | 没带调色 | 想要特定配色再补，不影响播放 |

## 6. 别做的事

- **别把别人的版权图提交进仓库**：自己机器上用没问题，提交就是你在再分发。仓库只放代码 + 自带三套自画风景（见根 README「仓库里的素材」）。
- **别改 `arts-builtin/` 里的三套**：那是随插件分发的样板，改了下次装可能被覆盖；要改就复制出来另起一套。
- **别手拼素材 URL**：页面侧套件的画面地址只能从开屏插件的清单里取，拼路径在版本升级后会断。
