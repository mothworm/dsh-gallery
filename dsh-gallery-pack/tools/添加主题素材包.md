# 添加你自己的主题素材包（可验证）

`dsh-gallery` 是一个**通用的**换肤框架：开屏播什么、桌面是什么，全由你的素材目录决定。
本仓库随包只带三套自画风景（清寒 / 暖秋 / 夜潮），其余主题——**任何人的任何主题**——都可以做成一包导入进来。

这份文件教你怎么加，以及**怎么确认真的加成功了**。

---

## 0. 目录契约：一套主题就是一个文件夹

```
~/.dsh/boot-naruto/arts/            ← 所有主题都放这儿
├── scenery-cool/                   ← 一套主题 = 一个目录
│   ├── preset.json                 ← 必须
│   ├── 01.jpg  02.jpg  03.jpg  04.jpg   ← 幕图,NN.jpg 命名
│   └── eye.png                     ← 可选,悬浮球图案
├── scenery-warm/
└── 你的主题/
    ├── preset.json
    ├── 01.jpg …
    └── eye.png
```

> Windows 上 `~` 是 `%USERPROFILE%`，macOS/Linux 上是 `$HOME`。

### preset.json 最小可用例子

```json
{
  "schema": 1,
  "id": "my-theme",
  "title": "我的主题",
  "open": "none",
  "eye": { "kind": "photo", "photo": "eye.png" },
  "acts": [
    { "dur": 900, "pos": "50% 45%", "z0": 1.04, "z": 1.10, "file": "01.jpg" },
    { "dur": 900, "pos": "50% 45%", "z0": 1.04, "z": 1.10, "file": "02.jpg" }
  ]
}
```

| 字段 | 必须 | 说明 |
|---|---|---|
| `schema` | ✅ | 必须是 `1` |
| `id` | ✅ | 必须**和目录名一致** |
| `title` | 建议 | 面板上显示的名字 |
| `open` | — | `"none"` = 不要开场云；不写则用默认 |
| `eye` | 建议 | 悬浮球图案，见第 4 节 |
| `acts[]` | ✅ | 至少一条；每条一个 `file`。**一张图就是"一幕"**，多张会在壁纸轮播里轮着换 |

`acts[]` 里其它字段都是可选的动画参数（`dur` 毫秒、`pos` 背景定位、`z0`/`z` 推镜倍率）。

---

## 1. 三件套：少一件会怎样

| 件 | 落点 | 缺了会怎样 |
|---|---|---|
| 开机画面 | `acts[].file` + 那些图 | **整套不可用**，面板显示"不可用" |
| 桌面壁纸 | **同一批图** | —（"选开屏 = 换桌面"就是靠共用同一批图实现的） |
| 悬浮球图案 | `eye.photo` | **不报错**，但球心变成灰色占位眼 |

第三行是要留心的：它**不会**给你任何错误提示，看起来"就是那个样式"。
所以下面的验证步骤里有一条专门查它。

---

## 2. 导入：三种方式

### 方式 A：用导入脚本（推荐，会先校验）

仓库里带了 `dsh-gallery-pack/tools/import-theme.py`：

```bash
# 先试跑,什么都不改
python dsh-gallery-pack/tools/import-theme.py /path/to/你的素材包

# 确认无误再写入
python dsh-gallery-pack/tools/import-theme.py /path/to/你的素材包 --apply
```

它接受**目录**或 **zip**，支持一次导入多套。导入前按宿主的口径校验，不合格的拒入并说明原因。

### 方式 B：手工复制

直接把主题目录拷进 `~/.dsh/boot-naruto/arts/` 即可。没有安装步骤、没有注册表。

### 方式 C：只放一套

```
mkdir -p ~/.dsh/boot-naruto/arts/my-theme
cp preset.json 01.jpg 02.jpg eye.png ~/.dsh/boot-naruto/arts/my-theme/
```

---

## 3. 刷新

**不用重启 DSH。** 宿主的清单是**每次请求都重扫磁盘**的，所以：

**刷新页面（`Ctrl+Shift+R` / `Cmd+Shift+R`）** → 点悬浮球 → 面板里就多出你那套。

---

## 4. 悬浮球图案怎么做

`eye.photo` 指向主题目录里的一个文件名。两种口径：

```json
"eye": { "kind": "photo", "photo": "eye.png" }
```

- **`photo`**：该目录下真实存在的图片文件名（png/jpg/webp）。球只有 74px，
  **建议 256×256 的正方形**，裁成圆形——给带直角的方图会露出四个角。
- **不写 `photo`**：客户端在手绘一套纹章图案（`kind` 决定画哪种）。
  这是"没有准备图"时的回退，能用，但不如自己的图好看。

> `kind` 取 `photo` 时会自动**停转**（照片转起来是歪的）。
> 其它 kind 里 `kunai`、`paper` 也停转，因为它们是"器物"不是"瞳术"。

## 5. 验证：怎么确认真的加成功了

### ① 看清单（最直接）

面板标题会显示 `主题壁纸 · 共 N 套`。N 比你导入前多几，就是进了几套。

### ② 跑校验（能查出"静默失败"）

```bash
# 查素材目录本身
python dsh-gallery-pack/tools/build-index.py --arts ~/.dsh/boot-naruto/arts --verify
```

期望最后一行是 `N 套可用, 0 套有问题`，退出码 0。

它会逐套检查"三件套"，把问题点名：

```
my-theme    我的主题    4  eye.png (缺)    eye.photo 指向的 eye.png 不存在(悬浮球会退回占位眼)
```

### ③ 看日志（排查用）

`~/.dsh/boot-naruto/boot.log` 里每次渲染都会记一行。挑这些关键字看：

| 日志里出现 | 含义 | 要不要管 |
|---|---|---|
| `ballPhoto=photo` | 球心图正常加载 | — |
| `ballPhoto=drawn` | 走手绘图案（没写 `photo` 时正常） | — |
| `ballPhoto=fallback` | 照片加载失败，退回手绘 | **要查**，多半是文件没拷全 |
| `palette-missing` | 这套没有调色文件 | 正常，用默认配色 |
| `preset-not-usable` | 这套缺 `preset.json` 或幕图 | **要查** |

### ④ 界面里点一遍

逐套点过去，确认：背景换了、球心有图案、悬停显示 `<主题名> · <图案名>`。

## 6. 常见错误

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 面板里整套"不可用" | 缺 `preset.json`，或 `acts[].file` 指向的图不存在 | 对照第 1 节补齐 |
| 球心是灰的 | 没写 `eye`，或 `photo` 指向的文件不存在 | 补图或补字段 |
| 整套不出现 | `id` 与目录名不一致 / `schema` 不是 1 | 改名或改值 |
| 改了没反应 | 没硬刷新 | `Ctrl+Shift+R` |
| "下一张"不工作 | 这套只有 1 张图 | 至少 2 张才有得换 |
| 图很糊 | 分辨率太低 | 建议竖构图 ≥ 832×1216（桌面聊天区是竖的） |
